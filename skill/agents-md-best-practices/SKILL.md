# agents-md-best-practices

收录遵守 [AGENTS.md 开放规范](https://github.com/agentsmd/agents.md) 的通用提示词工程最佳实践，供 Agent 在开发项目时加载使用。

## 使用方式

当用户需要加载某个 AGENTS.md 守则时，根据需求从下方索引中选择合适的文档，将对应 md 文件内容复制到项目根目录的 `AGENTS.md` 文件中，运行本地 Agent 后提示加载即可。
